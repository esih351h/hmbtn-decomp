Rucksack selective Xdelta build kit
==================================

Purpose
-------
This source change adds the Plus-style one-item split to the gameplay R2 exchange path.
It changes only player.c in the farm overlay. It does not alter the storage-window code,
seed stacking, cabinet/icebox behavior, graphics, events, or audio.

Behavior
--------
- R2's normal forward exchange requests mode 2.
- If the first bag slot contains a category-0 item with count >= 2 and the hand is empty,
  exactly one item is copied to the hand and the bag count is reduced by one.
- Category 0 is the game's crop/dish category. Seeds (category 2) and other items fall
  through to the original mode-0 exchange.
- Reverse exchange mode 1 and tool exchange are unchanged.

Files
-----
src/overlay/11_GF_FARM/people/player.c
  Complete replacement source file, based on the current main-branch file.

.github/workflows/rucksack-build.yml
  GitHub Actions workflow. It builds the project and uploads the farm overlay and EXE.

How to use
----------
1. Create a branch named feature/rucksack-split-xdelta from tools/xdelta322-runner.
2. Replace src/overlay/11_GF_FARM/people/player.c with the file in this kit.
3. Add .github/workflows/rucksack-build.yml to the same path in the repository.
4. Commit both files. The workflow should run automatically.
5. Download the artifact named rucksack-selective-build and provide it here.

The final custom disc and Xdelta are not generated by this workflow. They must be built
against the user's original USA BIN, then decoded and verified before testing in DuckStation.

Important
---------
This is a first-pass source implementation, not yet a tested game patch. Do not replace
your current game or delete your existing save. Test on a copy after the final Xdelta is
built and verified.
